## 📲 How to Install & Share

### For Personal Use:
1. **Copy APK**: Navigate to `app/build/outputs/apk/debug/`
2. **Transfer**: Copy `app-debug.apk` to your Android device
3. **Install**: 
   - Enable "Install from Unknown Sources" in Settings
   - Tap the APK file to install
   - Follow installation prompts

### For Sharing:
1. **Share File**: Send `app-debug.apk` via:
   - Email attachment
   - Cloud storage (Google Drive, Dropbox)
   - File sharing apps
   - USB transfer

2. **Recipients Need**:
   - Android device (API 24+ / Android 7.0+)
   - "Unknown Sources" installation enabled
   - Internet connection (for Firebase & Gemini API)
